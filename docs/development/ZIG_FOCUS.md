# Current focus: pure Zig

## Active
- Engine, project, persistence, config, MIDI and audio: Zig (`src/`).
- Raven graphics and widgets: Zig port in `vendor/raven/zig` (C sources are archived in `vendor/raven/deprecated-c`).
- UI kit: Zig retained-mode widgets in `src/uikit` (demo: `zig build uikit-demo`).
- Command-line tool and test harness: Zig (`src/cli`, `tests/e2e`).

## Ported (2026-11-13)
- The application window (`src/ui/raven_app.c`, 5.5k lines) is Zig: `src/ui/zig/app/` holds a 1:1 translation split
  by area (`widgets`, `mixer_tracks`, `project`, `settings_transport`, `piano`, `actions_popout`, `mixer`,
  `control`), with the shared constants, types and globals in `state.zig`, the engine prototypes in `externs.zig`,
  libc in `libc.zig`, and `fns.zig` (generated by `gen_fns.py`) as the flat namespace the C had.
- Its helpers (`window_input`, `ui_state`, `palette`, `ui_math`, `input_dispatch`; `keymap`, `knob_math`,
  `piano_math` were already Zig) are Zig modules under `src/ui/zig/`. Their C tests are Zig tests in `tests/ui/`.
- The UI library compiles no C. The headless command-socket session, the saved project and the exported WAV are
  byte-identical to the C build, and `tests/e2e/smoke.sh` passes.
