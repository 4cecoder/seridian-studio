# Reference samples (not shipped)

`reference/samples/` holds real recordings of drum hits and instrument notes, used only to
compare against our physical and synth models. Audio here is never committed or shipped.

Each downloaded pack gets a `SOURCE.md` in its folder with: origin URL, author, licence
(exact text or link), and the date downloaded. Only sources with a clear licence are used:
CC0, or CC-BY with attribution recorded here.
